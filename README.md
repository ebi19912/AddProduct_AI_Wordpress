# AI Woo Generator

AI Woo Generator is a WordPress plugin designed to automate and accelerate WooCommerce product creation using Artificial Intelligence (LLMs), with seamless integration for Rank Math SEO.

## Features
- **AI-Powered Product Generation:** Automatically generate WooCommerce products including content, tags, and short descriptions using external LLM APIs.
- **Rank Math Integration:** Automatically generate SEO metadata compatible with Rank Math.
- **Customizable API Settings:** Configure your preferred API Provider, Endpoint URL, API Key, Model, and System Prompt.
- **WordPress Standards:** Built following WordPress security standards and an MVC-like structure for better maintainability.

## Installation
1. Upload the `ai-woo-generator` directory to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to the newly added "هوش مصنوعی ووکامرس" (AI WooCommerce) menu in your WordPress dashboard.
4. Navigate to "تنظیمات API" (API Settings) to configure your API credentials and model preferences.
5. Start generating products!

# تولیدکننده محصولات ووکامرس با هوش مصنوعی (AI Woo Generator)

افزونه AI Woo Generator یک افزونه وردپرسی برای تولید سریع محصولات ووکامرس با استفاده از هوش مصنوعی (LLM) و هماهنگ با Rank Math می‌باشد.

## ویژگی‌ها
- **تولید محصول با هوش مصنوعی:** تولید خودکار محصولات ووکامرس شامل محتوا، برچسب‌ها و توضیحات کوتاه با استفاده از APIهای خارجی LLM.
- **یکپارچگی با Rank Math:** تولید خودکار متادیتای سئو هماهنگ با افزونه Rank Math.
- **تنظیمات API قابل شخصی‌سازی:** امکان پیکربندی ارائه‌دهنده API، آدرس API، کلید API، مدل و پرامپت سیستم.
- **استانداردهای وردپرس:** ساخته شده بر اساس استانداردهای امنیتی وردپرس و ساختار مشابه MVC.

## نصب و راه‌اندازی
۱. پوشه `ai-woo-generator` را در مسیر `/wp-content/plugins/` آپلود کنید.
۲. افزونه را از طریق منوی 'افزونه‌ها' در وردپرس فعال کنید.
۳. در پیشخوان وردپرس به منوی جدید "هوش مصنوعی ووکامرس" بروید.
۴. وارد "تنظیمات API" شوید و اطلاعات API و مدل مورد نظر خود را تنظیم کنید.
۵. از تولید محصولات با هوش مصنوعی لذت ببرید!
